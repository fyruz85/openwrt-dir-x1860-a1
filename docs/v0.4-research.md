# v0.4 research gates and image audit

The v0.3 build passed compilation and basic FIT listing. The previous inspection did not actually assert the embedded DTB controller status. This revision adds an independent FIT default-configuration DTB extraction and fail-closed NAND/PCIe checks. No board or package changes.

Stock evidence: three identical embedded DTBs, FIT integrity hashes verified, rootfs at 0x340000, two 43 MiB firmware slots. The observed recovery UI has only an upload control; it is not a demonstrated RAM boot mechanism. The B1 UBI layout is incompatible evidence for an A1 installer.

Wi-Fi: stock logs identify MT7915 family and GPIO19 PCIe reset. Upstream B1 uses pcie1, factory EEPROM 0x0/0xe00 and precal 0xe10/0x19c10, plus config2 MAC cells. These are B1-only facts, not A1 offsets. Do not apply them. A1 needs PCI enumeration, actual factory calibration layout and MAC provenance; no radio-enabled runnable image until verified. The driver package is not a substitute for calibration.

Physical gate: obtain a documented nonpersistent boot path and read-only hardware evidence (bootloader version/commands, PCI enumeration, calibration metadata and MAC source, live flash map). Do not upload or flash anything to obtain these facts. No persistent image or radio candidate enabled.
