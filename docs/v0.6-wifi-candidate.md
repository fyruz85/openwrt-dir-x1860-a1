# v0.6 — Wi-Fi integration candidate (documentation only)

Baseline: v0.5 ad8bbdbf916d7f9b6f78d0e1b8790d3e29f256eb, Actions run 45507218251 successful. No runnable source changes.

## Evidence and limits

A1 public stock boot log: https://openwrt.org/inbox/toh/d-link/dir-x1860_a1 . NAND is 128 MiB, erase block 128 KiB, page 2048 bytes. Factory partition spans 0x100000–0x180000, corroborating owner stock DT. This establishes partition geometry, not that the radio driver uses that partition as its calibration base. Relative EEPROM/precal clues 0, 0xe00, 0xe10 must not be treated as verified physical addresses. Stock factory signature is wrgax10_dlink_dirx1860; encrypted factory format differs from B1 SGE format. Stock log shows serial failsafe prompt, not a verified Ethernet-only entry path.

Reference B1 implementation: https://lists.infradead.org/pipermail/lede-commits/2025-October/027569.html . Its factory partition geometry matches but its config2 partition starts at 0x180000, where A1 firmware begins. Do not copy its MAC cells, PCIe slot or calibration length. Driver default EEPROM fallback is not proof of valid board calibration.

## Non-runnable device-tree design

Future fixed-layout NVMEM provider: read-only factory partition, only after calibration base and data are verified. Future radio node: compatible mediatek,mt76 under VERIFIED_PCIE_ROOT; reg determined by enumeration; nvmem-cells EEPROM_VERIFIED and PRECAL_VERIFIED; band MAC cells only after derivation is verified. These symbolic placeholders are intentionally not compilable and must never enter port/ or build scripts. Do not enable NAND or PCIe in current runnable images.
