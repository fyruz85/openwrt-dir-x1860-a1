# v0.3 Ethernet candidate

Stock A1 evidence identifies GMAC1 RGMII to PHY4. Use the pinned upstream B1 GMAC1 binding pattern only, not its flash layout or LAN numbering. PHY4 is assigned exclusively to GMAC1, with switch port 4 disabled and PHY interrupt removed as in upstream B1. Preserve the existing GMAC0/DSA CPU link configuration rather than translating vendor TRGMII settings without validation. Four logical LAN ports remain. OpenWrt board defaults create LAN and WAN interfaces; WAN DHCP and standard firewall/NAT defaults are expected, not runtime verified. MAC derivation and physical port order remain unknown. No NAND, PCIe, persistent images or load-address changes. Test only via verified nonpersistent RAM boot on isolated network; check MAC uniqueness, link, DHCP, NAT, WAN isolation and WireGuard before deployment.
